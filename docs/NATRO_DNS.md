# Natro — Sadece Nameserver (Cloudflare için)

Domain **passla.com.tr** Natro'da kayıtlı. DNS kayıtlarını **Natro'da değil**, **Cloudflare'de** yöneteceksin.

Natro'da **ücretli Profesyonel DNS alma**.

## Natro'da yapılacak tek şey

1. [natro.com](https://www.natro.com) → **passla.com.tr**
2. **DNS Değiştir** (DNS Sunucuları bölümü)
3. Cloudflare'in verdiği 2 nameserver'ı yapıştır (ör. `xxx.ns.cloudflare.com`)
4. Kaydet

## Natro'da yapma

- Profesyonel DNS satın alma
- A kaydı ekleme
- Hosting satın alma
